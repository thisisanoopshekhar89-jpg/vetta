# Contributing to Vetta

Thanks for the interest — but please read this first, because Vetta is not a
conventional open-source project.

## Vetta is proprietary

The source is public so it can be **read and evaluated**. It is not licensed for
use, and contributions are accepted only by prior arrangement. See [LICENSE](LICENSE).

## Before you open a pull request

**Please email first** — `thisisanoopshekhar89@gmail.com`. Unsolicited pull
requests may have to be closed unmerged, which wastes your time, and I would
rather not do that to you.

If we agree on a change, note that submitting it assigns copyright in that
contribution to the author unless we agree otherwise in writing.

## Things that are always welcome, no permission needed

- **Bug reports.** Especially a false positive: a legitimate résumé that Vetta
  flags. Those matter more than new features, because a wrong flag can cost a real
  candidate a real job.
- **A missed evasion technique.** If you know a way to hide text that Vetta does
  not catch, please tell me. That is the whole point of the tool.
- **Corrections to the documentation.**

When reporting a detection problem, a **synthetic** sample document is ideal.
Please do not send anyone's real résumé — it is personal data, and I do not want it.

## If you want to use Vetta

Open the "Request permission" link under [New issue](../../issues/new/choose), or
email directly. Say what you want to do with it and at what volume. Reasonable
requests get a yes.
